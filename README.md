### 💡 How I like to build

- Clean Code, SOLID and Clean Architecture over clever code
- Write down the *why*: ADRs for every significant decision
- Privacy by design: store the minimum, and let users own their data
- Test pyramid: JUnit/Mockito → Testcontainers → Vitest → Playwright
- Use AI to amplify engineers, not replace judgement
